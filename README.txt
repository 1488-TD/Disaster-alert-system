# AS-2 Disaster Alert & Communication System

A complete front-end educational prototype for:

"Establishing an effective system for real-time communication of disaster alerts to authorities and the public."

## Files
- index.html — UI and page structure
- style.css — responsive professional styling
- script.js — live alert logic, dashboard updates, filtering, map simulation and browser persistence

## How to run
1. Keep all three files in the same folder.
2. Open `index.html` in Chrome, Edge, Safari or Firefox.
3. Use Public Dashboard to view alerts.
4. Open Authority Dashboard to publish an alert.
5. The alert immediately appears in the public feed and changes the map zone status.
6. Reloading the page keeps demo alerts because they are stored in localStorage.

## Demo features
- Public dashboard
- Authority dashboard
- Create/delete alerts
- High/medium/low priority
- Live-looking alert feed
- Alert statistics
- Disaster type filter
- Interactive simulated map
- Risk zones
- Shelter/hospital/emergency HQ markers
- Emergency resource buttons
- Responsive mobile layout
- Local browser persistence

## Important
This is a simulation for an academic project. It does not connect to government emergency systems, real SMS gateways, official warning feeds or real maps.

## Next step for a production-style project
Use a backend such as Firebase/Supabase/Node.js, role-based authentication, verified official data sources, real push/SMS notification services, real geospatial data, audit logs, and secure server-side validation.
