AS-2 PROJECT

Real-Time Disaster Communication

A college-level prototype demonstrating how an alert can move from an authority interface to a public safety interface.

Project objective

Establish an effective system for communicating disaster alerts to authorities and the public. The prototype emphasizes speed, clarity, location awareness and safety instructions.

System flow

Authority→Alert Server→Public Feed→Safety Action

Suggested real-world architecture

  • Government/official data sources for verified disaster information.
  • Backend API + real-time database for alert distribution.
  • Push notifications/SMS for subscribed users.
  • Map service for affected zones and evacuation points.
  • Role-based authentication for authorized personnel.
  • Audit logs and alert expiry/versioning.
